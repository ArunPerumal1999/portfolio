# Portfolio - Arun Kumar P

> **Full-Stack Developer** | PHP (Laravel, CodeIgniter), React.js, Next.js, MySQL, RESTful APIs

A modern, high-performance, and fully responsive personal portfolio website showcasing full-stack web development projects, interactive Web/Admin dashboard previews, career timeline, technical skills, and resume.

---

## 🌟 Key Features

- **📱 Fully Mobile Responsive**: Seamless layout across mobile devices, tablets, and desktops with a modern slide drawer menu, backdrop blur, and touch-optimized controls.
- **🔄 Interactive Project Sliders**: Automatic and manual switching between live **Web View** and **Admin View** with touch swipe gestures on mobile and keyboard navigation.
- **📄 Interactive Resume Modal**: Clean, printable resume viewer modal with download actions and comprehensive professional summary.
- **💼 Career Timeline & Experience**: Interactive work history highlights at *WayToSoft Technologies* and *Techzarinfo*.
- **📊 Skills & Services**: Categorized technical skills (Frontend, Backend, Databases, Tools) and service offerings.
- **💬 Direct Contact**: Integrated contact form, WhatsApp floating action button, and direct email/phone links.

---

## 🛠️ Built With

- **HTML5 & CSS3** (Custom responsive design, CSS variables, glassmorphism)
- **JavaScript (ES6+)** (Dynamic sliders, touch gestures, smooth scrolling, modal system)
- **Font Awesome 5 & 6** (Modern icon set)
- **Google Fonts** (Poppins, Outfit, Fira Code)
